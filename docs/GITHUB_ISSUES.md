## Stage Completion Rule

Sebelum issue tahap ditutup:

- PRD sudah dibaca sebelum dan sesudah pengerjaan.
- Acceptance criteria tahap terpenuhi atau gap disetujui user.
- `docs/WORK_LOG.md` sudah diperbarui.
- Report detail dibuat di `docs/agent-reports/` jika pekerjaan besar.
- Checks relevan sudah dijalankan dan dicatat.
- Commit sudah dibuat dan dipush ke GitHub.
- User sudah memberi approval tahap.
